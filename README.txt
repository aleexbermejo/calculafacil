# CalculaFácil
Web estática de calculadoras online.

ANTES DE PUBLICAR:
1. Sustituye TU-DOMINIO.com en index.html, robots.txt y sitemap.xml.
2. Completa los datos entre corchetes de aviso-legal.html y privacidad.html.
3. Cambia el correo de contacto de contacto.html.
4. Añade el código de AdSense únicamente después de tener el sitio aprobado y configura Privacidad y mensajes/CMP de Google para el tráfico de EEE, Reino Unido y Suiza.
5. Envía sitemap.xml a Google Search Console.
